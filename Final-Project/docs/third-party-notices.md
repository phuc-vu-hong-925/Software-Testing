# Thành phần bên thứ ba

Maven Wrapper 3.3.2 (Apache License 2.0): scripts từ repository apache/maven-wrapper và JAR từ Maven Central. Các header bản quyền được giữ trong scripts. Maven, Selenium, JUnit và JaCoCo được Maven tải từ repository theo pom.xml; gói này không kèm Chrome, ChromeDriver hoặc JDK.
